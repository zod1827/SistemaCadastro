# SistemaCadastro

Projeto desenvolvido para a atividade prática de Controle de Versão e Gerenciamento de Mudanças com Git e GitHub.

## Menu do sistema

```text
=== Sistema de Cadastro ===
1 - Cadastrar usuário
2 - Listar usuários
3 - Excluir usuário
0 - Sair
```

## Análise

### 1. Qual a finalidade de uma branch?

Uma branch permite criar uma linha de desenvolvimento separada da principal. Assim, podemos desenvolver uma nova funcionalidade sem alterar diretamente a versão principal do projeto.

### 2. Qual a diferença entre commit e merge?

O commit registra uma alteração realizada no projeto, criando um ponto no histórico do sistema.

O merge é utilizado para integrar as alterações de uma branch em outra, como integrar uma funcionalidade desenvolvida em uma branch na branch principal.

### 3. Por que é importante utilizar mensagens claras nos commits?

Mensagens claras facilitam a compreensão do histórico do projeto. Dessa forma, outros desenvolvedores conseguem identificar facilmente o que foi alterado em cada commit.

### 4. Por que o controle de versão é importante em equipes de desenvolvimento?

O controle de versão permite que várias pessoas trabalhem no mesmo projeto de forma organizada. Ele também mantém um histórico das alterações, facilita a colaboração e permite recuperar versões anteriores quando necessário.

### 5. O que representa a versão 1.1.0 no contexto desta atividade?

A versão 1.1.0 representa a versão do sistema após a inclusão da opção de excluir usuário. O primeiro número representa a versão principal, o segundo representa a inclusão de uma nova funcionalidade e o terceiro representa correções ou alterações menores.
